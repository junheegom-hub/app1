# 버튼 앱

> 간단한 버튼을 눌러 안내 메시지를 확인하는 앱입니다.

## 📱 사용 방법

1. 화면에 **"버튼을 눌러주세요."**라는 문구가 나타납니다.
2. 버튼을 눌러주세요.
3. 버튼을 누르면 **"버튼이 눌렸습니다."**라는 메시지가 표시됩니다.

## ✨ 특징

- 간단하고 직관적인 버튼
- 버튼을 누르면 즉시 메시지 표시
- 누구나 쉽게 사용할 수 있는 간단한 앱

## 🔘 버튼 안내

**버튼을 눌러주세요.**

⬇️

**버튼이 눌렸습니다.**
